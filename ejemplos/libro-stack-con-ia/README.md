# Ejemplo 1 — Libro: Stack de desarrollo de Software con IA

Primer producto completo del pipeline: un libro didáctico de **15 capítulos** sobre cómo armar un stack de desarrollo con IA, dirigido a programadores.

**Cómo se hizo** (pipeline de 4 capas, corridas del 23 al 25 de octubre de 2026):

1. **Alcance por entrevista** — bootstrap del pipeline editorial: manifiesto del libro (audiencia, registro divulgativo, idioma español mexicano), voz, índice, outline con capítulos en estado DRAFT-READY
2. **Redacción por capítulo** — tres pasadas editoriales (borrador → edición de desarrollo → copyedit) + aparato didáctico por capítulo: objetivos de aprendizaje, preguntas de reflexión, puntos clave, glosario, ejercicios
3. **Diseño** — tipografía editorial (serif 11pt, interlineado ~130%), portada full-bleed, índice navegable
4. **Verificación** — evaluación final de "editor adquisidor" leyendo el PDF completo en frío + revisión visual página por página

El PDF completo está aquí: [`Stack-de-desarrollo-de-Software-con-IA.pdf`](Stack-de-desarrollo-de-Software-con-IA.pdf)
